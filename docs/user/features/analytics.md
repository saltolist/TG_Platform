# Аналитика

Раздел **Аналитика** показывает статистику подключённого Telegram-канала на
основе реальных данных синхронизации.

## Что показывается

### Топ-посты
Таблица самых просматриваемых постов за период с колонками:
- Превью текста поста
- Просмотры
- Репосты
- Реакции

### Метрики канала
- Просмотры, реакции, комментарии, репосты и ER постов
- Подписчики из Telegram, если канал отдаёт это число
- Динамика по выбранному периоду: 24 часа, 7/30/90 дней или всё время
- Тепловая карта активности по дням недели и времени публикации

Для реальных аккаунтов интерфейс не показывает демо-графики: если данных ещё
нет, вы увидите пустое состояние. Демо-данные остаются только в demo/guest
режиме.

## Как собираются данные

- Метрики постов берутся из Telegram-синхронизации: просмотры, реакции,
  комментарии и репосты.
- Число подписчиков читается из Telegram. Если Telegram скрывает подписчиков
  канала, в интерфейсе вместо фейковой оценки используется пустое значение.
- История метрик сохраняется снимками каждые 30 минут. Поэтому график за
  24 часа постепенно заполняется 30-минутными точками после подключения.
- Дневные периоды используют реальные снимки, а для дней до первого снимка —
  backfill по датам публикации уже синхронизированных постов.
- Тепловая карта строится по UTC-времени публикации постов и их просмотрам.

## Как использовать

1. Перейдите в раздел **«Аналитика»** через sidebar.
2. Выберите временной период (день / неделя / месяц / 90 дней / всё время).
3. Изучите топ-посты — найдите форматы, которые работают лучше всего.
4. Нажмите на пост в таблице — перейдёт в рабочую область поста.

## Подсказки по интерпретации

- **Высокие просмотры + мало реакций** — контент читают, но не вовлекает.
- **Высокие реакции + мало просмотров** — узкая аудитория, но лояльная.
- **Много репостов** — виральный контент, стоит повторить формат.

## Требования

Аналитика работает только при **подключённом Telegram-канале** в режиме синхронизации «история + живые данные».
